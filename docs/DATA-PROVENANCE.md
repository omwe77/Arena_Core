# ARENA_CORE — Data Provenance

## Overview

This document describes all data sources used in ARENA_CORE, what is archived/historical, and what is simulated. Maintaining clear boundaries between these two categories is critical for user trust and product credibility.

### Simulated / Hypothetical Data

All simulation results generated by the Poisson model. Clearly labeled as "SIMULATION" throughout the UI.

- Match scores and scorers
- Tournament brackets and progression
- Standings after simulation
- Goal events and timelines
- Penalty shootout outcomes

## Data Labels in the UI

| Label | Meaning | Where Used |
|-------|---------|------------|
| `ARCHIVE DATA` | Historical, bundled competition data | Standings view, archive view, data badges |
| `SIMULATION` | Hypothetical, model-generated result | Simulator view, match center, simulation results |
| `HISTORICAL` | Past season data | Archive cards, provenance badges |

## Data Integrity

### Validation Checks

- All team names are unique within each competition
- Standings positions are sequential (1, 2, 3, ...)
- Points are consistent with W/D/L records
- Goal differences are calculated correctly
- Top scorers have valid goal counts

### Known Limitations

- **No real-time data** — all data is from past seasons
- **No play-by-play events** — only final scores and scorers
- **No player statistics** — only team-level data
- **No head-to-head history** — only aggregate statistics

## Data Update Process

To update archived data:

1. Edit `data/real-tournaments.js`
2. Update the `actualSeason` field for each competition
3. Verify all data integrity checks pass
4. Run `npm test` to validate
5. Commit with message: `data: update archived competition data for <season>`

## External Resources

### Team Logos

- **Source**: `flagcdn.com` (national teams), `images.fotmob.com` (club teams)
- **Caching**: Logos are loaded on demand and cached by the browser
- **Fallback**: If a logo fails to load, a placeholder is shown

### Hero Videos

- **Source**: YouTube (embedded via iframe)
- **Loading**: Videos load only when a competition is selected
- **Fallback**: If a video fails to load, a static background image is shown

### Fonts

- **Source**: Google Fonts (Chakra Petch, Outfit, Share Tech Mono)
- **Loading**: Loaded via `<link>` tags in HTML head
- **Fallback**: System font stack if Google Fonts is unavailable

## Security Considerations

- **No API keys** — all data is bundled client-side
- **No user data collection** — no analytics or tracking
- **No backend** — all processing happens in the browser
- **CORS** — external resources (logos, videos) are loaded from their respective CDNs with appropriate CORS headers
